### About Me

I am a motivated **Full-Stack Web Developer** and IT Graduate from the **University of Science and Technology of Southern Philippines (USTP)**, majoring in **Database and Information Systems**.

I specialize in building production-grade, highly performant, and beautifully designed web applications. I love crafting seamless user interfaces with **React** and **Next.js**, orchestrating reliable serverless backends and database architectures with **Supabase** and **PostgreSQL**, and building functional, user-centric systems that solve real-world problems.

### 📂 Featured Works & Projects

Here is a curated selection of systems and applications I've built, highlighting my journey from client deliverables to production-grade SaaS platforms:

#### 💼 1. [DigiTEC](https://ectec-digitec.vercel.app) — Cooperative Fund & Loan Monitoring System
*My Capstone project and first client deliverable, designed to digitize ECTEC Cooperative's financial records.*
* **Features:** Robust Role-Based Access Control (RBAC) with 5 user roles, complete secure loan request-to-approval workflow, dynamic interest calculations (via `Decimal.js` to ensure transaction accuracy), members profile management, and automatic financial report exports in Excel/PDF format.
* **Tech Stack:** `React 19` | `Vite` | `Supabase` | `PostgreSQL` | `Redux Toolkit` | `TanStack Query` | `Tailwind CSS` | `DaisyUI` | `Recharts` | `Vercel`
* **Links:** 🌐 [Live Demo](https://ectec-digitec.vercel.app) | 💻 [Source Code](https://github.com/FrancisPadero-GitHub/vite-digitec-js)

#### 🏢 2. [Klicktiv](https://www.klicktiv.io) — Financial Orchestration Platform
*A SaaS solution centralizing operations for field service businesses (HVAC, chimney, dryer vent companies) to replace tedious spreadsheets.*
* **Features:** Complete job and technician management, automatic real-time calculation of commission/profit splits, technician revenue dashboards, advanced date filters, and data export.
* **Tech Stack:** `React` | `Next.js` | `TypeScript` | `Tailwind CSS` | `Shadcn/UI` | `Supabase CLI` | `Deno Edge Functions` | `PostgreSQL`
* **Links:** 🌐 [Live Platform](https://www.klicktiv.io)

#### 🤖 3. [Nexhire](https://www.nexhire.work) — AI-Driven Intelligent Hiring Platform
*An advanced recruitment system designed to leverage artificial intelligence for resume screening and interviews.*
* **Features:** Intelligent resume parsing, automated AI-driven audio/video candidate interviews, administrative applicant dashboards, custom tracking tables.
* **Tech Stack:** `Next.js` | `React 19` | `TypeScript` | `Supabase` | `Google Gemini API (@ai-sdk/google)` | `Vapi AI` | `TanStack Table` | `Radix UI`
* **Links:** 🌐 [Live Platform](https://www.nexhire.work)

#### 💰 4. [WealthWise](https://vite-wealthwise.vercel.app/) — Personal Budget Monitoring App
*A comprehensive financial app that empowers users to take control of their daily finances.*
* **Features:** Automated balance tracking, customized budgets with visual overspending alerts, interactive expenditure charts, and automated bill reminders.
* **Tech Stack:** `React 19` | `Vite` | `Supabase` | `Material UI (MUI)` | `TanStack Query` | `Vercel`
* **Links:** 🌐 [Live Demo](https://vite-wealthwise.vercel.app/) | 💻 [Source Code](https://github.com/FrancisPadero-GitHub/vite-wealthwise-final)

#### 🎓 5. [BrewScholar](https://www.brewscholar.app) — Student Hub for Filipino Scholars
*An all-in-one productivity and community portal for Filipino students.*
* **Features:** Directory for scholarship discoveries, personal budget tracker, media entertainment explorer (via TMDB API integration), live peer-to-peer chatroom, file hosting portal, and a built-in Gemini-powered AI Assistant.
* **Tech Stack:** `React 19` | `Next.js 16` | `TypeScript` | `Tailwind CSS v4` | `Zustand` | `TanStack Query` | `Axios` | `Supabase`
* **Links:** 🌐 [Live Website](https://www.brewscholar.app) | 💻 [Source Code](https://github.com/FrancisPadero-GitHub/brewscholar)

#### ✈️ 6. [APSP](https://github.com/FrancisPadero-GitHub/Airline_Passenger_Satisfaction_Prediction) — Airline Passenger Satisfaction Prediction
*A Machine Learning project focused on analyzing passenger experience metrics.*
* **Features:** Random Forest Classifier model training and deployment, data preprocessing pipelines, lightweight Flask backend API, and a beautiful interactive Streamlit UI for single or batch CSV uploads.
* **Tech Stack:** `Python` | `Scikit-learn` | `Flask` | `Streamlit` | `Pandas` | `StandardScaler`
* **Links:** 💻 [Source Code](https://github.com/FrancisPadero-GitHub/Airline_Passenger_Satisfaction_Prediction)

#### 🧹 7. [TipTop Maid Services](https://github.com/FrancisPadero-GitHub/tiptop-maid-services) — Service Web Application
*A modern and responsive landing page and interactive booking website for domestic cleaning services.*
* **Features:** Intuitive services showcase, aesthetic image gallery of cleaning works, dynamic pricing calculator, and a full scheduling and reservation booking system.
* **Tech Stack:** `Next.js 16` | `React 19` | `Tailwind CSS v4` | `Radix UI` | `Next Themes`
* **Links:** 💻 [Source Code](https://github.com/FrancisPadero-GitHub/tiptop-maid-services)

#### 📊 8. [AVSPH Financials Dashboard](https://github.com/FrancisPadero-GitHub/avsph-financials) — Financial Analytics Tool
*A custom, lightweight administrative portal for a Virtual Assistant services agency.*
* **Features:** Integrated live billing system, automatic visual revenue charting, transaction ledger, and client invoice generation with PDF exports.
* **Tech Stack:** `Vanilla HTML5` | `CSS3` | `JavaScript (ES6)` | `Supabase Client SDK` | `Chart.js` | `jsPDF` + `jspdf-autotable`
* **Links:** 💻 [Source Code](https://github.com/FrancisPadero-GitHub/avsph-financials)
